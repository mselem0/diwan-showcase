# مِشكاة — AlDiwan API Showcase

تجربة عربية تفاعلية مبنية بالكامل على بيانات **AlDiwan API** الحية. لا تستخدم Mock Data ولا تضمّن أي مفتاح داخل المستودع.

## ما الذي تختبره؟

- استعراض القصائد وترقيم الصفحات والفلاتر: العصر، البحر، الغرض، القافية ونمط القصيدة.
- عرض الأنماط الجديدة بصورة صحيحة:
  - `vertical / hemistichs`: كل سطرين شطرا بيت عمودي.
  - `prose / lines`: سطور القصيدة النثرية.
  - `free_verse / stanzas`: مقاطع شعر التفعيلة.
- البحث الموحد في الشعراء والقصائد.
- فتح شاعر واستعراض «كوكبته» الشعرية.
- «باب المصادفة» لاختيار قصيدة عشوائية من كامل الكتالوج.
- «بصمة الإيقاع» التي تحوّل أطوال أسطر القصيدة إلى أثر بصري.
- التحكم في حجم الخط والتشكيل والنسخ مع حفظ الإسناد للمصدر.
- Live API Console تعرض endpoint والحالة ووقت الاستجابة والحصة المتبقية.
- اختبار endpoints المرجعية: العصور والبحور والأغراض والقوافي والعدادات.

## الأمان

لا يوجد API key في الشفرة. عند فتح الصفحة تُطلب قيمة مؤقتة وتحفظ في `sessionStorage` فقط، وتُحذف عند إغلاق جلسة المتصفح أو الضغط على «قطع الاتصال».

لأن GitHub Pages يعمل داخل المتصفح، استخدم **مفتاح اختبار فقط** مع:

- Allowed origin: `https://mselem0.github.io`
- أقل scopes لازمة: `poets.read` و`poems.read`
- حصة محدودة وتاريخ انتهاء قريب.

لا تستخدم مفتاح Live دائمًا أو غير مقيّد في تطبيق Frontend عام.

## التشغيل المحلي

```bash
python3 -m http.server 4173 --bind 127.0.0.1
```

ثم افتح `http://127.0.0.1:4173`، وأضف هذا الـorigin مؤقتًا إلى Allowed Domains في مشروع الاختبار إذا أردت اختبار API محليًا.

المشروع Vanilla HTML/CSS/JavaScript ولا يحتاج build step أو dependencies.
