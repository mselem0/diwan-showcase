# 📜 روائع الديوان | Diwan Showcase Web App

تطبيق ويب تفاعلي عالي الأداء والأناقة لاستعراض عيون الشعر العربي الأصيل وربطه مباشرة بـ **API منصة الديوان**، مع دعم كامل للعمل دون اتصال (Offline-first Fallback)، وتصدير بطاقات الاقتباس كصور، وقراءة الشعر بشطرين متقابلين متوازنين.

## ✨ المميزات الرئيسية

1. **عرض شعري كلاسيكي بشطرين متقابلين:**
   - تصميم هندسي مخصص للشعر العمودي العربي (`.verse-sadr` و `.verse-ajuz`).
   - تكيّف تلقائي ومرن (Responsive) على شاشات الهواتف المحمولة والأجهزة اللوحية.
2. **التحكم الفوري بالتشكيل وحجم الخط:**
   - إمكانية إزالة أو إعادة التشكيل والحركات الإعرابية بنقرة زر واحدة عبر محرك Regex فوري دون إعادة تحميل.
   - تصغير وتكبير حجم الخط المريح للعين بنسب مئوية سلسة.
3. **صانع بطاقات الاقتباسات (Quote Card Maker):**
   - نسخ منسق لأي بيت شعري مع اسم الشاعر وعنوان القصيدة.
   - تصدير فوري لبطاقة البيت كصورة عالية الدقة (`PNG`) عبر محرك `HTML5 Canvas` مع خلفية رخامية وإطارات وزخارف إسلامية ذهبية.
4. **تكامل متقدم ومباشر مع API الديوان (ApiClient):**
   - اتصال حي 100% بدون بيانات وهمية أو ستاتيك.
   - يدعم إدخال رابط الخادم المخصص ورمز المصادقة (`Bearer Token`).
   - فحص حي للاتصال عبر مسار `GET /eras` القياسي مع معالجة قيود CORS وأخطاء 403.
   - مؤشرات تحميل (Skeletons & Spinners) أثناء جلب البيانات وواجهة أخطاء تفاعلية مع إمكانية إعادة المحاولة وضبط الإعدادات.
5. **بحث حي فوري (Live Instant Search):**
   - استعلام مباشر من الخادم للبحث في الشعراء والقصائد والأشطر الشعرية.

## 🚀 التشغيل السريع (Local Development)

التطبيق مبني وفق معمارية الويب النقية الخفيفة (Pure Vanilla JS + Tailwind CSS + Lucide Icons) بدون الحاجة إلى تثبيت أي حزم ثقيلة أو أدوات بناء معقدة.

### تشغيل عبر متصفح الويب مباشرة:
يمكنك فتح ملف `index.html` في أي متصفح حديث فوراً.

### أو تشغيله عبر سيرفر محلي خفيف:
```bash
# باستخدام Python 3
cd showcase
python3 -m http.server 8080

# أو باستخدام Node.js npx
npx serve .
```
ثم افتح المتصفح على: `http://localhost:8080`

## 🔌 الربط بـ API منصة مطوري الديوان

يتيح التطبيق ربطاً سلساً مع منصة الديوان أو أي بروكسي API متوافق عبر واجهة الإعدادات المدمجة:

1. انقر على أيقونة **الإعدادات ⚙️** أو على شارة حالة الاتصال في الشريط العلوي.
2. أدخل رابط الخادم (الافتراضي: `https://api.aldiwan.net/api/v1` أو عنوان سيرفرك المحلي `http://localhost:3000/api`).
3. أدخل رمز المصادقة الخاص بك (`Bearer Token`).
4. اضغط على **«فحص الاتصال (Ping)»** للتأكد من استجابة الخادم.
5. اضغط على **«حفظ الإعدادات»**؛ يتم حفظها محلياً وبشكل آمن في `localStorage` لمتصفحك فقط.

### نقاط النهاية المتوافقة (Endpoints Supported):
- `GET /eras` — فحص الاتصال وقائمة العصور الأدبية.
- `GET /poets?era={eraId}` — استرجاع شعراء عصر معين أو الكل.
- `GET /poets/{poetId}/poems` — استرجاع قصائد الشاعر المختار.
- `GET /poems/{poemId}` — استرجاع تفاصيل القصيدة وأبياتها.
- `GET /search?q={query}` — البحث في الشعراء والقصائد.

## 🌐 النشر على GitHub Pages بضغطة زر

تم تضمين ملف `.nojekyll` مسبقاً لضمان تحميل وتفسير كافة ملفات التنسيق والوسائط دون تدخل محرك Jekyll.

### خطوات التفعيل على المستودع:
1. ارفع الملفات إلى مستودعك على GitHub:
   ```bash
   git add showcase/
   git commit -m "feat: add diwan showcase web app"
   git push origin main
   ```
2. ادخل إلى إعدادات المستودع على GitHub: **Settings** -> **Pages**.
3. تحت تبويب **Build and deployment**:
   - المصدر (**Source**): اختر `Deploy from a branch`.
   - الفرع (**Branch**): اختر `main` واضبط المسار على `/ (root)` أو مجلد `/docs` في حال نقل المجلد له، أو قم بنشر فرع منفصل `gh-pages` يحتوي محتويات مجلد `showcase`.
4. بعد لحظات، سيصبح التطبيق متاحاً على رابط عمومي مجاني بصيغة:
   `https://<username>.github.io/<repo-name>/showcase/`
